# レクタースライドスタイルガイド

## デザイン哲学

- **美麗でシンプル** 情報過多を避け、視覚的にクリーン
- **色数制限** グレースケール基調に限定的なアクセントカラー
- **可読性重視** フォントサイズと余白を適切に
- **一貫性** パターンの繰り返しで理解しやすく

---

## カラーパレット

### プライマリグラデーション

```css
background: linear-gradient(to right, #1B4565, #3E9BA4);
```

### グレースケール

| クラス | 用途 | カラーコード |
|--------|------|-------------|
| gray-50 | パネル背景（淡い） | #f9fafb |
| gray-100 | パネル背景（やや濃い） | #f3f4f6 |
| gray-600 | サブテキスト | #4b5563 |
| gray-700 | 見出しテキスト | #374151 |
| gray-800 | メインテキスト | #1f2937 |

### アクセントカラー

| 色名 | カラーコード | 用途 |
|------|-------------|------|
| 濃紺（Navy） | #1B4565 | グラデーション左、プライマリアクセント |
| ティール（Teal） | #3E9BA4 | グラデーション右、セカンダリアクセント |
| ルビーピンク（Ruby） | #c70067 | 対比・強調のみ（限定的使用） |

**重要ルール** 1スライドあたりアクセントカラーは1-2色まで

## タイポグラフィ

### フォントサイズ体系（emベース）

| クラス | サイズ | 用途 | 使用例 |
|--------|--------|------|--------|
| text-em-3xl | 3em | 数値強調、インパクトのあるキーワード | 統計値、KPI |
| text-em-2xl | 2em | パネル見出し、セクションタイトル | カードタイトル |
| text-em-xl | 1.5em | サブ見出し | H3レベル |
| text-em-lg | 1.25em | 本文、リスト項目 | 標準テキスト |
| text-em-base | 1em | 補足説明 | キャプション |

### フォントウェイト

- **font-bold** (700): 見出し、強調
- **font-semibold** (600): サブ見出し
- **font-normal** (400): 本文

## レイアウトパターン

### 基本原則

1. **余白を大切に** gap-4（1rem）〜gap-6（1.5rem）を標準とする
2. **パディング統一** p-6（1.5rem）を基本とする
3. **角丸統一** rounded-xl（0.75rem）または rounded-lg（0.5rem）
4. **影の控えめ使用** shadow-lg を基本とし、過度な装飾を避ける

### グリッドシステム

- **2カラム** `grid grid-cols-2 gap-6`
- **3カラム** `grid grid-cols-3 gap-4`
- **4カラム** `grid grid-cols-4 gap-3`（テキスト少なめ）
- **2x2** `grid grid-cols-2 grid-rows-2 gap-4`

## パネルデザインパターン

### 基本パネル

```html
<div class="bg-gray-50 rounded-xl shadow-lg p-6">
  <!-- コンテンツ -->
</div>
```

### 強調パネル（左ボーダー）

```html
<div class="bg-gray-100 rounded-xl shadow-lg p-6 border-l-4 border-gray-500">
  <!-- コンテンツ -->
</div>
```

### グラデーションパネル

```html
<div class="rounded-xl shadow-lg p-6"
     style="background: linear-gradient(135deg, #1B4565 0%, #3E9BA4 100%);">
  <p class="text-white"><!-- コンテンツ --></p>
</div>
```

## 禁止事項（文体ルール）

### ❌ 使用禁止

1. **コロン（：）** タイトルに使用しない
   - 悪い例: `原則❶：自律性の最大化`
   - 良い例: `原則❶ 自律性の最大化`

2. **感嘆符（！）・疑問符（？）** 理知的な文体を維持
   - 悪い例: `AIで開発が10倍速に！`
   - 良い例: `AIで開発が10倍速に`

3. **装飾的な絵文字** 🧩 🎯 🚀 など
   - 悪い例: `🧩 問題領域の複雑さ`
   - 良い例: `問題領域の複雑さ`

4. **派手な色による強調** red-600, green-600, yellow-500
   - 悪い例: `<p class="text-red-600">重要</p>`
   - 良い例: `<p class="text-gray-700 font-bold">重要</p>`

## ベストプラクティス

### スライドタイトル

- **1行に収める** 長すぎる場合は簡潔に
- **具体的に** 抽象的なタイトルを避ける
- **数字を使う** 「3つの原則」など

### コンテンツ配置

- **1スライド1メッセージ** 情報を詰め込みすぎない
- **視覚的階層** 見出し → 本文 → 補足説明の順に明確に
- **ホワイトスペース** 余白を恐れない

### 配色ルール

- **背景はグレー系** 白背景は避ける（目に優しい gray-50/100）
- **テキストはグレー800** 純黒（#000）は使わない
- **アクセントは1-2色** 多色使いを避ける
