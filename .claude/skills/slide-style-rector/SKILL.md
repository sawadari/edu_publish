# slide-style-rector

スライドファイルを読み込み、レクタースタイルガイド（docs/slide-style-guide.md）に準拠するよう自動整形します。

## 整形内容

### 1. 文体チェック

- **コロン（：）の削除**
  - タイトルや見出しから自動削除
  - 例: `原則❶：自律性` → `原則❶ 自律性`

- **感嘆符（！）・疑問符（？）の削除**
  - 理知的な文体を維持
  - 例: `AIで開発が10倍速に！` → `AIで開発が10倍速に`

- **装飾絵文字の削除**
  - 🧩 🎯 🚀 などの装飾的絵文字を削除
  - 例: `🧩 問題領域の複雑さ` → `問題領域の複雑さ`

### 2. スタイル適用

- **カラーコードの統一**
  - #1B4565（濃紺）、#3E9BA4（ティール）、gray系のみ使用
  - red-600/green-600 → gray-600/gray-700へ自動変換

- **フォントサイズクラスの統一**
  - text-em-* クラスの使用を推奨
  - text-3xl → text-em-3xl のような変換

### 3. レイアウトパターン適用

- **slides/example.mdから最適なパターンを提案**
  - 現在のスライド構造を分析
  - 40パターンから最適なものを推薦

- **グリッドシステムの適用**
  - gap-4/gap-6への統一
  - パディング・角丸の統一（p-6, rounded-xl）

## 使用方法

/slide-style-rector [ファイル名]

## 実行フロー

1. **対象ファイルを読み込み**
   - slides/presentations/[ファイル名].mdを読み取る

2. **スタイルガイドチェック**
   - docs/slide-style-guide.mdのルールに照らし合わせて検証
   - 違反箇所をリスト化

3. **自動修正**
   - 文体ルール違反を自動修正
   - カラーコードを統一
   - クラス名を標準化

4. **パターン提案**
   - 現在のレイアウトを分析
   - slides/example.mdから最適なパターンを推薦

5. **レポート出力**
   - 修正箇所のサマリー
   - 手動対応が必要な箇所の一覧
   - 推奨パターンの提案

## 実装方針

このスキルはClaude Codeのネイティブ機能（Read/Edit tool）を使用して実装されます。

### チェック項目

#### 文体ルール
- [ ] コロン（：）が使われていないか
- [ ] 感嘆符（！）や疑問符（？）が使われていないか
- [ ] 装飾絵文字が使われていないか

#### スタイルルール
- [ ] カラーコードがレクター準拠か（#1B4565, #3E9BA4, gray系）
- [ ] red-600, green-600が使われていないか
- [ ] text-em-* クラスが使われているか

#### レイアウトルール
- [ ] グリッドシステムのgap値が統一されているか（gap-4/gap-6）
- [ ] パディングが統一されているか（p-6）
- [ ] 角丸が統一されているか（rounded-xl/rounded-lg）
- [ ] 1スライドあたりアクセントカラーが1-2色以内か

## 参照ファイル

- **docs/slide-style-guide.md** レクタースタイルガイド本体
- **slides/example.md** 40種類のレイアウトパターン
- **CLAUDE.md** プロジェクト全体の文体ルール

```
【手動対応が必要】
⚠ スライド5: 画像パスが相対パスではありません（/images/flow.png）

```

## 注意事項

- **バックアップ不要**: 修正前の状態はGit履歴から復元可能
- **段階的修正**: 大規模な修正は段階的に適用し、ビルドして確認
- **パターン提案は任意**: 推奨パターンは参考情報であり、適用は任意

## 関連コマンド

- `/marp-build` 修正後のスライドをビルド
- `/marp-preview` プレビューサーバーで確認
