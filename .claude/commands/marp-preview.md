# /marp-preview

Marpスライドをブラウザでプレビューします。

## 使用方法

```
/marp-preview
```

## 実行内容

1. `npm run marp:server`を実行
2. http://localhost:8080 でプレビューサーバーを起動
3. ファイル変更を自動検知
4. ブラウザで自動リロード

## プレビューサーバーの特徴

### ホットリロード

- Markdownファイルを編集すると自動的に反映
- ブラウザを手動でリロードする必要なし
- スライド作成を効率化

### ナビゲーション

ブラウザでプレビュー中に以下のキーボード操作が可能:

- **→** または **Space**: 次のスライド
- **←** または **Shift+Space**: 前のスライド
- **Home**: 最初のスライドへ
- **End**: 最後のスライドへ
- **F**: フルスクリーン切り替え
- **P**: プレゼンターモード（ノート表示）

## アクセス方法

サーバー起動後、以下のURLでアクセス:

```
http://localhost:8080
```

複数のスライドファイルがある場合、ファイル一覧が表示されます。

## 停止方法

プレビューサーバーを停止するには:

1. ターミナルで`Ctrl+C`を押す
2. または Claude Code のタスク停止機能を使用

## Watch モード

ファイル監視のみ行い、サーバーを起動しない場合:

```bash
npm run marp:watch
```

→ `slides/output/`に自動ビルドされます

## 使用シーン

### スライド作成中

1. `/marp-preview`でサーバー起動
2. エディタでMarkdownを編集
3. ブラウザで即座に確認
4. 繰り返し

### プレゼンリハーサル

1. `/marp-preview`でサーバー起動
2. ブラウザで`F`キーを押してフルスクリーン
3. プレゼンターモード（`P`キー）でノート確認
4. 本番と同じ操作で練習

## トラブルシューティング

### ポート8080が使用中の場合

別のアプリケーションがポート8080を使用している場合:

```bash
# ポートを変更して起動
marp -s slides/presentations/ --html --allow-local-files -p 3000
```

### 自動リロードが動作しない場合

1. ブラウザのキャッシュをクリア
2. サーバーを再起動
3. ファイル保存が確実に行われているか確認
